# Dawa Saathi — GitHub Pages

Dawa Saathi is a static medicine-batch tracker built with HTML, CSS, and JavaScript. It needs no server, database, build command, or account setup.

## Publish with GitHub Pages

1. Create a GitHub repository. A public repository works with GitHub Free.
2. Upload the project files and folders to the repository root. Make sure `index.html` is at the root and keep the `assets/` folder beside it.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch (usually `main`) and the `/(root)` folder, then click **Save**.
6. Wait for the Pages deployment to finish. GitHub will display the website URL in the Pages settings and in the Actions deployment.

For a project named `dawa-sathi`, the URL is usually `https://YOUR-USERNAME.github.io/dawa-sathi/`. A repository named `YOUR-USERNAME.github.io` uses `https://YOUR-USERNAME.github.io/`.

## Files to publish

```text
index.html
assets/app.js
assets/style.css
README.md
```

There are no PHP endpoints in this GitHub Pages version. GitHub Pages serves static site files; it does not run the account backend from the former ProFreeHost version.

## Data and privacy

Batch and medicine records are stored in this browser's local storage. They do not sync across browsers or devices. Clearing browser data removes the records. This app does not include sign-in or cloud backup.

Avoid entering sensitive medical information. Follow your clinician's or pharmacist's directions for medicine decisions.
